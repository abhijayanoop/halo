# Profile

Facts about you that Halo may use. Add one bullet per fact. Halo writes them for you
when you say "remember that ...", and you can type them here yourself too.

A memory is a bullet that ends with its source and trust in square brackets, written
as src and trust each followed by two colons and a value, then a date, and a block id
that starts with a caret. Halo adds all of that when it saves one, so you rarely need
to type it.

Delete a line here and Halo forgets it.
